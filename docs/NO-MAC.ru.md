# Установка без Mac (Windows + iPhone)

AlpineiOS можно собрать только на macOS с Xcode, но **запускать** готовую
сборку можно без Mac. Для этого нужны две вещи:

1. подписанное development-сертификатом приложение (sideload);
2. StikDebug — он включает JIT на самом iPhone.

JIT обязателен: без него VM не создаётся. Подробное объяснение —
[NO-JIT.ru.md](NO-JIT.ru.md).

## Что понадобится

- iPhone с iOS 17 или новее (проект тестировался на iPhone 14 Pro, iOS 27).
- Windows-ПК с USB-кабелем — только для первоначальной установки и pairing-файла.
- Apple ID. Бесплатного достаточно: подпись живёт 7 дней, потом приложение нужно
  переподписать. Ограничение — 3 приложения на бесплатный аккаунт.
- Интернет на телефоне: образ Phosh скачивается при первом запуске
  (~1,9 ГБ, нужно ≥5 ГБ свободного места).

## Шаги

### 1. Установщик sideload-приложений

На Windows поставьте один из инструментов, которые умеют подписывать IPA вашим
Apple ID и обновлять подпись по Wi-Fi:

- **SideStore** (рекомендуется) — <https://sidestore.io>;
- **AltStore Classic** — <https://altstore.io>;
- **Sideloadly** — <https://sideloadly.io>.

Инструкции и требования к версиям смотрите на сайтах проектов: они меняются
чаще, чем этот документ. Общий смысл один: войти в Apple ID, настроить подпись
(7 дней для бесплатного аккаунта) и включить обновление по Wi-Fi.

### 2. Pairing-файл

StikDebug общается с отладочным сервисом iOS, поэтому ему нужен pairing-файл
устройства. Он создаётся на компьютере один раз:

- в SideStore/AltStore pairing-файл создаётся в процессе настройки;
- отдельно можно использовать `jitterbugpair` или `iloader`.

Сохраните файл — он понадобится и установщику, и StikDebug.

### 3. Установка AlpineiOS

1. Скачайте готовый IPA: <https://github.com/Lumid-Off/AlpineiOS/releases>.
   Берите `AlpineiOS-v0.2.1-alpha-unsigned.ipa` (или более новый unsigned-релиз).
   Если в форке появится собственный релиз, можно использовать и его.
2. Установите IPA через SideStore/AltStore/Sideloadly. Инструмент подпишет его
   вашим сертификатом; приложение получит entitlement `get-task-allow`, без
   которого StikDebug не сможет включить JIT.
3. На iPhone откройте **Настройки → Конфиденциальность и безопасность → Режим
   разработчика** и включите его (телефон перезагрузится).

### 4. Установка StikDebug

1. Скачайте IPA StikDebug: <https://github.com/StephenDev0/StikDebug/releases>.
2. Установите его тем же способом, что и AlpineiOS.
3. Откройте StikDebug и импортируйте pairing-файл.

### 5. Включение JIT и первый запуск

1. Откройте AlpineiOS и скачайте образ Phosh (или импортируйте свой).
2. Если JIT ещё не активен, нажмите **Enable JIT with StikDebug**. Приложение
   откроет StikDebug по схеме `stikjit://`, тот подключится к процессу и выдаст
   исполняемый регион.
3. Вернитесь в AlpineiOS. Статус должен смениться на `Live ...`; VM запустится
   автоматически.
4. Дальше Linux загружается сам. Первый запуск распаковывает диск и ставит
   выбранные приложения — это занимает время.

## Если что-то не работает

- **`Waiting for debugger`** — JIT не выдан. Проверьте, что приложение
  установлено именно с development-подписью (get-task-allow), а StikDebug
  импортировал pairing-файл. Перезапустите оба приложения.
- **`Failed: TXM selftest rejected RX execution`** — iOS 26/27 не разрешила
  исполнение. Перезапустите приложение и повторите включение JIT; на некоторых
  версиях iOS помогает перезагрузка телефона.
- **Приложение перестало открываться через 7 дней** — истекла подпись.
  Переподпишите его в SideStore/AltStore.
- **Не хватает места** — образу нужно около 5 ГБ; распакованный диск занимает
  до 8 ГБ виртуально, но реально — только записанные данные.

## Чего этот способ не даёт

- Он не убирает JIT и не ускоряет эмуляцию сам по себе.
- Он не позволяет собрать приложение без Mac — только запустить уже собранное.
- Бесплатный Apple ID требует переподписи каждые 7 дней и ограничивает число
  приложений.
